# LT 3D Converter

Отдельная программа для ПК: берёт модель `.obj` и превращает её в текст, который понимает окно **Little Importer** в LittleTiles (Minecraft 1.21.1). Мод Minecraft для этого не нужен.

## Как пользоваться
1. Запустите программу, выберите `.obj`.
2. Выберите цвет: один цвет, текстуру-картинку или материалы из `.mtl`.
3. Задайте алгоритм, сетку и макс. размер (длина самой длинной стороны модели в тайлах сетки).
4. Ползунком «Нагрузка на ПК» выберите, какую часть процессора можно использовать. Его можно двигать и во время работы.
5. «Конвертировать». Внизу видно прогресс, сколько прошло и сколько осталось.
6. «Копировать в буфер обмена» (или «Сохранить в .txt»).
7. В игре: Little Importer → вставьте текст в поле → Import. Нужен Little Blueprint в слоте импорта (в креативе слот может быть пустым).

## Алгоритмы
* **Срезы** — каждый треугольник модели становится одним наклонным боксом. Быстро, гладкие поверхности, один цвет на треугольник.
* **Воксели** — поверхность набирается кубиками 1×1×1 тайл. Медленнее и более «блочно», зато цвет берётся из текстуры по каждому кубику.

## Запуск
* **Windows (.exe)**: в GitHub Actions скачайте артефакт `LT3DConverter-windows`, распакуйте и запустите `LT3DConverter.exe`. Java ставить не нужно.
* **.jar**: артефакт `lt3dconverter-jar` или `./build-local.sh`. Запуск `java -jar lt3dconverter.jar` (нужна Java 17+) или `run.bat`.

## Командная строка
```
java -jar lt3dconverter.jar model.obj out.txt --mode voxels --size 64 --grid 16 --cpu 50 --texture tex.png
```
Все параметры: запустите без аргументов `model.obj out.txt`.

## Формат
Результат — SNBT-текст блюпринта, тот же, что даёт окно экспорта LittleTiles (тип `data`):
`{t:{"littletiles:colored_clean":[[I;цвет],[I;бокс],...]},size:[I;x,y,z],min:[I;x,y,z],tiles:N,boxes:M}`

## Ограничения
* Текст проверен на соответствие формату по исходникам LittleTiles и собственным тестам, но вставка в сам Minecraft не проверялась.
* Очень большие модели дают очень длинный текст (мегабайты). Если игра не принимает вставку — уменьшите макс. размер или сетку.
* Допустимые значения сетки зависят от настроек LittleTiles на вашем клиенте/сервере.
* Экспорт из LittleTiles обратно в .obj не реализован.
